# 🌟 موقع وكلاء محترفين

موقع ويب بسيط، احترافي، ومتجاوب (Responsive) باللغة العربية لعرض فريق الوكلاء المحترفين وخدماتهم.

## ✨ المميزات

- 🎨 تصميم عصري بألوان متدرجة وتأثيرات حركية ناعمة
- 📱 متجاوب بالكامل مع جميع الأجهزة (ديسكتوب / تابلت / موبايل)
- 🌐 دعم كامل للغة العربية واتجاه RTL
- 🖼️ 6 أقسام رئيسية: الرئيسية، من نحن، الوكلاء، الخدمات، تواصل معنا، الفوتر
- 👥 بطاقات وكلاء ديناميكية (تُولد من JavaScript)
- 📋 نموذج تواصل يعمل مباشرة مع رسالة تأكيد
- ⬆️ زر العودة للأعلى
- 🍔 قائمة موبايل أنيقة
- ⚡ تأثيرات ظهور عند التمرير (Scroll animations)

## 🚀 كيفية التشغيل

لا يحتاج أي build أو أدوات — فقط افتح الملف في المتصفح:

```bash
# من داخل المجلد
open index.html
```

أو استخدم خادم محلي بسيط:

```bash
# باستخدام Python
python3 -m http.server 8000

# أو باستخدام Node (npx)
npx serve .
```

ثم افتح المتصفح على `http://localhost:8000`.

## 📂 الملفات

| الملف | الوصف |
|---|---|
| `index.html` | هيكل الموقع الأساسي |
| `styles.css` | جميع التنسيقات والتصميم |
| `script.js` | التفاعلات والديناميكا (بطاقات الوكلاء، النموذج، إلخ) |
| `README.md` | هذا الملف |

## ✏️ التخصيص

- لتعديل بيانات الوكلاء، حرّر مصفوفة `agents` في `script.js`.
- لتغيير الألوان الأساسية عدّل قيم الـ `:root` في `styles.css`.
- لتغيير وسائل التواصل والمعلومات، حرّر قسم `contact-info` في `index.html`.
